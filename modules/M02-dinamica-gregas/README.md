## Ideia-chave

O GBM é o modelo padrão de trajetória: log-preço gaussiano, preço log-normal. Serve para stress, sizing e checks de hedge — **não** para confundir μ histórico com preço justo de opção (isso vive no mundo risco-neutro, M01.A05).

## Ordem sugerida

1. Ler o README do Lab 01  
2. Rodar `run_lab.py`  
3. Variar `sigma` e observar a “abertura do túnel”  
4. Seguir para gregas (próximo lab)
