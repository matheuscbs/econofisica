# Glossário rápido

| Termo | Significado curto |
|-------|-------------------|
| **GBM** | Geometric Brownian Motion — \(dS = \mu S\,dt + \sigma S\,dW\) |
| **Drift μ** | Tendência do retorno; na precificação risco-neutra vira \(r\) |
| **Vol σ** | Intensidade da difusão; “abertura do túnel” estatístico |
| **Log-preço** | \(X_t = \ln S_t\); sob GBM, \(X_T\) é gaussiano |
| **Correção Itô** | Termo \(-\tfrac12\sigma^2\) no drift do log |
| **Monte Carlo** | Estimar esperanças amostrando muitas trajetórias |
| **ddof=1** | Variância amostral com denominador \(N-1\) (não viesada) |
| **Risco-neutro Q** | Medida sob a qual o preço é esperança descontada |
| **Smile / skew** | Forma da IV vs strike |
| **Regime** | Estado estatístico do mercado (vol, correlação, entropia) |
